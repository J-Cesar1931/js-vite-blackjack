# BlackJack Vite

Pasos para arrancar proyecto:

1. Clonar repositorio
2. Ejecutar ```npm install``` para reconstruir los módulos de node
3. Correr el Dev Server ```npm run dev```
4. Abrir proyecto en un navagador ```localhost:3000```

## Producción

1. Ejecutar ```npm run build```
2. Tomar la carpeta ```dist``` y desplegarla en un servidor
